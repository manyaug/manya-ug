# Manya Design System (v4.0)

Welcome to the **Manya Design System**, a premium, playful, kid-adventure branding system created for the Manya educational platform. 

The aesthetic is styled as **"Sunny Day" (Light Mode)** and **"Starry Night" (Dark Mode)**, mixing warm tactile materials (3D toy-like elements, gloss effects, smooth spring transitions) with clean modern layout spaces.

---

## 1. Color Palette

### Core Palette (HSL)
*   **Manya Purple**: `hsl(262, 83%, 58%)` — The signature brand color, used for hero accents, elite headers, and major interaction elements.
*   **Manya Pink**: `hsl(330, 70%, 51%)` — Playful secondary color, used for success celebrations and specific subject markers.
*   **Manya Gold**: `hsl(38, 92%, 50%)` — Warm yellow, used for trophies, achievements, gold leagues, and active rewards.
*   **Manya Green**: `hsl(161, 84%, 39%)` — Eco/nature green, used for correct answers, progress completions, and success highlights.

### Subject Branding
To help students navigate fields of study, each subject has a designated color theme:
*   **Mathematics**: Violet/Purple (`#7c3aed` / Light: `#ede9fe`)
*   **Science**: Emerald Green (`#10b981` / Light: `#ecfdf5`)
*   **Social Studies (SST)**: Warm Amber (`#f59e0b` / Light: `#fffbeb`)
*   **English**: Rose Pink (`#db2777` / Light: `#fdf2f8`)

### Theme-Specific Backgrounds & Borders
#### ☀️ Sunny Day (Light Mode)
*   **Page Background**: `#FFF8F0` (Warm Cream)
*   **Secondary BG / Inset**: `#FFF5EB` (Light Peach-Cream)
*   **Card Background**: `#FFFFFF` (Pure White)
*   **Border Subtle**: `#F0E6D6`
*   **Border Color**: `#E8DDD0`
*   **Primary Text**: `#2D1B4E` (Deep Eggplant Slate)
*   **Secondary Text**: `#8B7FA3` (Warm Muted Grey)

#### 🌙 Starry Night (Dark Mode - Default)
*   **Page Background**: `#050714` (Deep Space Navy)
*   **Secondary BG / Inset**: `#0A0C1A` (Midnight Slate)
*   **Card Background**: `rgba(15, 23, 42, 0.6)` (Semi-transparent dark glass)
*   **Border Subtle**: `rgba(255, 255, 255, 0.1)`
*   **Primary Text**: `#F5F0FF` (Lavender White)
*   **Secondary Text**: `#9B8FB8` (Muted Indigo)

## 2. Typography

*   **Display Font (Headings, Game Titles)**: `'Fredoka'`, cursive/display — Friendly, rounded, bold letterforms that feel welcoming and energetic.
*   **Main Body Font**: `'Outfit'`, sans-serif — Super clean, high-readability geometric sans-serif that balances the playful display headings.
*   **Code / Monospace**: `'JetBrains Mono'`, monospace — Used for counters, numerical displays, and code sections.

### Type Scale
*   **Hero Headers (h1)**: `56px` / Tracking: `-1.68px` (Playful, tightly letter-spaced Fredoka)
*   **Subheadings (h2)**: `24px` / Line Height: `118%` (Fredoka or Outfit Bold)
*   **Body Text**: `18px` / Line Height: `145%` (Outfit Medium/Regular)
*   **Muted / Small Text**: `14px` (Outfit Regular)
